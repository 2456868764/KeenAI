- Qwen and Zhipu provider support for localized Chinese AI responses.
- Dashboard next-intl registration for 12 locales.
- Intercom users/admins plus conversations/messages import.
- KB `kb:release-gate` and `kb:bench:local` release checks.
- Config-backed `file`, shallow `web`, GitHub raw content, and Notion page/block KB source connectors.

- Root release typecheck uses `corepack pnpm -r --if-present typecheck` to avoid pnpm version drift.
