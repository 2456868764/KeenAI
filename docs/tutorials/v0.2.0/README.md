# v0.2.0 Tutorial Video Kit

Release scope: P3-12 YouTube / Bilibili tutorial assets.

This directory contains release-ready scripts and shot lists. It is not a substitute for published video links; final release still needs rendered uploads and links in `docs/releases/v0.2.0.md`.

## Videos

| Video | Target length | Asset |
|-------|---------------|-------|
| Self-hosted quickstart | 4-6 min | [self-hosted-quickstart.md](./self-hosted-quickstart.md) |
| KB import, eval, and bench | 5-7 min | [kb-import-eval-bench.md](./kb-import-eval-bench.md) |

## Recording setup

- Resolution: 1920x1080, 30fps.
- Terminal font: 16px minimum.
- Browser zoom: 100%.
- Locale: English UI with Chinese subtitles or Chinese voiceover for Bilibili.
- Use a clean demo workspace and avoid showing production secrets.

## Required proof before closing P3-12

- Rendered MP4 files or upload URLs for both videos.
- YouTube title/description and Bilibili title/description copied from each script.
- Links added to [docs/releases/v0.2.0.md](../../releases/v0.2.0.md).
- Final checklist in [publishing-checklist.md](./publishing-checklist.md) completed.
