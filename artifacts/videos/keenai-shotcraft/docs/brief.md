# KeenAI video-shotcraft brief

## Goal

Create a 2-minute product/business explainer for KeenAI in Chinese, using video-shotcraft motion language and the Linear-inspired visual system already used in the BP deck.

## Reference Style

- Source reference: https://vincentwei1021.github.io/video-shotcraft/
- Local gallery cards used as motion vocabulary:
  - `scene-locked-title`: product-space title with perspective camera move.
  - `brand-frame-snap`: thick brand frame, hard color snap, product window drops in.
  - `ai-stream-response`: summary first, evidence rows flow in, finish state.
  - `integration-hub-map`: app tiles connect to a central intelligence panel.
  - `timeline-travel`: horizontal roadmap/process travel.
  - `panel-grid-moves`: cards reflow from row into structured grid.
  - `outro-group-photo-launch`: product elements gather into a final brand lockup.

## Visual System

- Canvas: near-black `#010102`.
- Panels: charcoal `#0f1011` / `#141516`.
- Text: `#f7f8f8`, muted `#d0d6e0`, subtle `#8a8f98`.
- Accent: Linear-style lavender blue `#5e6ad2`; secondary status colors for success/warning only.
- Typography: system sans fallback, dense product UI, no decorative hero-card treatment.

## Runtime

- Duration: 120 seconds.
- Frame rate: 30 fps.
- Resolution: 1920 x 1080.
- Format: MP4.
- Audio: local BGM plus transition, whoosh, click, sparkle, riser, and impact SFX.

## Content Arc

1. KeenAI is an AI-native support operating system.
2. It solves four enterprise pains: high support cost, scattered channels, weak data control, and workflow inconsistency.
3. Keeni AI Agent turns every inbound message into classified, grounded, actionable work.
4. RAG uses the knowledge base to produce cited answers instead of hallucinated replies.
5. Memory gives the agent durable context about customers, conversations, teams, and product state.
6. Workflow makes the agent operational: trigger, condition, action, and human approval.
7. Multi-channel intake covers widget, email, Discord, Slack, Telegram, API, and future MCP-style connectors.
8. Commercial plan targets SaaS founders/CTO, customer support leaders, enterprise IT/helpdesk, and product/feedback teams.
